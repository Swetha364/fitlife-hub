# FitLife Hub – Health and Fitness Awareness Website

FitLife Hub is a responsive health and fitness awareness website developed using HTML, CSS, and JavaScript. The website is designed to encourage users to adopt a healthy lifestyle by providing information about popular workouts, healthy habits, and fitness tips. It features a modern and user-friendly interface with a responsive design, workout cards, health tips, and a contact section. This project demonstrates front-end web development skills and provides an attractive platform to promote health and wellness.

## Project Objective

- Create a responsive health and fitness awareness website.
- Promote healthy living through fitness information and tips.
- Improve front-end web development skills using HTML, CSS, and JavaScript.
- Design a simple, attractive, and user-friendly website.

## Features

- Responsive design for different screen sizes.
- Attractive homepage with a hero section.
- About Us section with website information.
- Popular Workouts section with images and descriptions.
- Health Tips section with useful wellness advice.
- Contact form for user interaction.
- Interactive buttons using JavaScript alert messages.
- Clean and modern user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub

## Challenges Faced

- Creating a responsive layout for mobile and desktop devices.
- Designing an attractive and user-friendly interface.
- Organizing workout cards using CSS Flexbox.
- Building a responsive Health Tips section using CSS Grid.
- Implementing JavaScript for simple user interactions.
